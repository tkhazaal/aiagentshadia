# Rules and preferences

Living rules learned from Tania's and Shadia's approvals, corrections, and repeated instructions. A rule is never silently rewritten; it is marked superseded with a link to the newer one.

Rule ID format: OL-NNN (Olivia rules). Where the source names Tania's own operating rule IDs (R-009 no em dashes, R-014 never promise reconnection), they are cited alongside.

Each rule records: who set it, when, what it changes, source, status.
