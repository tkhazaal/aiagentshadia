# Olivia Knowledge Base (Shadia Assist)

This repository is the working memory for Olivia, the private AI copilot for Shadia (Tania Khazaal's content creator and podcast-growth coordinator).

It holds the knowledge Olivia needs to turn Tania's existing material into accurate, publish-ready content, and to answer questions about past decisions, approved claims, links, support patterns, and team instructions without repeating research or inventing answers.

Start at [00-index.md](00-index.md).

## Operating principles

- Retrieval first. Search this repo before answering a question about past work, a person, a link, a decision, or a prior response.
- One canonical home per fact. Summaries link to the source; they do not re-copy it.
- History is preserved. A changed decision or rule is marked superseded and linked to the newer one, never erased.
- Nothing is invented. Facts, quotes, testimonials, numbers, links, and personal-story details come from a source in `sources/` or from a confirmed team instruction. Anything else is labelled as a concept or pending.
- Olivia prepares. Olivia never publishes, schedules, sends a pitch, or confirms a guest.

## Status labels used in notes

| Label | Meaning |
|---|---|
| confirmed | Stated in a source file or by a team instruction, with a citation |
| pending | Known gap, waiting on the team |
| needs verification | Inferred, stale, or possibly changed |
| superseded | Replaced by a newer decision or rule (link included) |
