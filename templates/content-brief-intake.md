# Content brief intake

Before creating any content, pin these five down. If key information is missing, ask up to 3 focused questions. If Shadia says proceed anyway, state assumptions and use placeholders for unverified details.

1. Format and platform
2. Audience segment (see the audience list in [../brand/tania-method-and-voice.md](../brand/tania-method-and-voice.md))
3. Source material and the truth it supports (transcript, video, post, training, comment themes, approved brief; if none, label the output a concept requiring Tania's approval)
4. One desired outcome
5. CTA and approved link (check [../links/link-registry.md](../links/link-registry.md); if blank, "[confirm current link/claim]")
